## 2. 排序算法

### 2.1. 快速排序（Quick Sort）

**快速排序**是一种分治算法，通过选择一个基准元素，将数组分为两部分，然后递归排序。

#### 2.1.1. 算法原理

**基本思想**：

1. 选择一个基准元素（pivot）
2. 将数组分为两部分：小于基准的元素和大于基准的元素
3. 递归地对两部分进行排序

**形式化定义**：

设数组 $A = [a_1, a_2, \ldots, a_n]$，快速排序算法定义为：

$$
\text{QuickSort}(A) = \begin{cases}
A & \text{if } |A| \leq 1 \\
\text{QuickSort}(L) \cup \{p\} \cup \text{QuickSort}(R) & \text{otherwise}
\end{cases}
$$

其中：

- $p$ 是基准元素
- $L = \{a \in A: a < p\}$
- $R = \{a \in A: a > p\}$

#### 2.1.2. 算法实现

**Python实现**：

```python
def quick_sort(arr):
    """
    快速排序算法

    时间复杂度：
    - 平均情况：O(n log n)
    - 最坏情况：O(n²)
    - 最好情况：O(n log n)

    空间复杂度：O(log n)（递归栈）
    """
    if len(arr) <= 1:
        return arr

    # 选择基准元素（这里选择中间元素）
    pivot = arr[len(arr) // 2]

    # 分割数组
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]

    # 递归排序并合并
    return quick_sort(left) + middle + quick_sort(right)


# 原地排序版本（更高效）
def quick_sort_inplace(arr, low=0, high=None):
    """原地快速排序，节省空间"""
    if high is None:
        high = len(arr) - 1

    if low < high:
        # 分割并获取基准位置
        pivot_index = partition(arr, low, high)

        # 递归排序左右两部分
        quick_sort_inplace(arr, low, pivot_index - 1)
        quick_sort_inplace(arr, pivot_index + 1, high)


def partition(arr, low, high):
    """分割函数，返回基准元素的最终位置"""
    # 选择最后一个元素作为基准
    pivot = arr[high]

    # 小于基准的元素索引
    i = low - 1

    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]

    # 将基准元素放到正确位置
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1
```

**Rust实现**：

```rust
/// 快速排序算法（Rust实现）
pub fn quick_sort<T: Ord + Clone>(arr: &mut [T]) {
    if arr.len() <= 1 {
        return;
    }

    let pivot_index = partition(arr);
    let (left, right) = arr.split_at_mut(pivot_index);
    quick_sort(left);
    quick_sort(&mut right[1..]);
}

fn partition<T: Ord>(arr: &mut [T]) -> usize {
    let pivot_index = arr.len() - 1;
    let mut i = 0;

    for j in 0..pivot_index {
        if arr[j] <= arr[pivot_index] {
            arr.swap(i, j);
            i += 1;
        }
    }

    arr.swap(i, pivot_index);
    i
}
```

**Go实现**：

```go
// QuickSort 快速排序算法（Go实现）
func QuickSort(arr []int) {
    if len(arr) <= 1 {
        return
    }

    pivotIndex := partition(arr)
    QuickSort(arr[:pivotIndex])
    QuickSort(arr[pivotIndex+1:])
}

func partition(arr []int) int {
    pivot := arr[len(arr)-1]
    i := 0

    for j := 0; j < len(arr)-1; j++ {
        if arr[j] <= pivot {
            arr[i], arr[j] = arr[j], arr[i]
            i++
        }
    }

    arr[i], arr[len(arr)-1] = arr[len(arr)-1], arr[i]
    return i
}
```

#### 2.1.3. 复杂度分析

**时间复杂度**：

- **平均情况**：$T(n) = O(n \log n)$
  - 每次分割大约将数组分为两半
  - 递归深度为 $\log n$
  - 每层需要 $O(n)$ 时间

- **最坏情况**：$T(n) = O(n^2)$
  - 当基准元素总是最大或最小时
  - 递归深度为 $n$
  - 每层需要 $O(n)$ 时间

- **最好情况**：$T(n) = O(n \log n)$
  - 每次分割都完美平衡

**空间复杂度**：

- **平均情况**：$S(n) = O(\log n)$（递归栈）
- **最坏情况**：$S(n) = O(n)$（递归栈）

#### 2.1.4. 优化策略

1. **三路快排**：处理重复元素
2. **随机化基准**：避免最坏情况
3. **小数组使用插入排序**：减少递归开销

### 2.2. 归并排序（Merge Sort）

**归并排序**是一种稳定的分治排序算法，将数组分为两半，分别排序后合并。

#### 2.2.1. 算法原理

**基本思想**：

1. 将数组分为两半
2. 递归地对两半进行排序
3. 合并两个已排序的子数组

**形式化定义**：

$$
\text{MergeSort}(A) = \begin{cases}
A & \text{if } |A| \leq 1 \\
\text{Merge}(\text{MergeSort}(L), \text{MergeSort}(R)) & \text{otherwise}
\end{cases}
$$

其中 $L$ 和 $R$ 是数组的两半。

#### 2.2.2. 算法实现

**Python实现**：

```python
def merge_sort(arr):
    """
    归并排序算法

    时间复杂度：
    - 所有情况：O(n log n)

    空间复杂度：O(n)
    """
    if len(arr) <= 1:
        return arr

    # 分割数组
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    # 合并两个已排序的子数组
    return merge(left, right)


def merge(left, right):
    """合并两个已排序的数组"""
    result = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    # 添加剩余元素
    result.extend(left[i:])
    result.extend(right[j:])

    return result
```

**Rust实现**：

```rust
/// 归并排序算法（Rust实现）
pub fn merge_sort<T: Ord + Clone>(arr: &[T]) -> Vec<T> {
    if arr.len() <= 1 {
        return arr.to_vec();
    }

    let mid = arr.len() / 2;
    let left = merge_sort(&arr[..mid]);
    let right = merge_sort(&arr[mid..]);

    merge(&left, &right)
}

fn merge<T: Ord + Clone>(left: &[T], right: &[T]) -> Vec<T> {
    let mut result = Vec::with_capacity(left.len() + right.len());
    let mut i = 0;
    let mut j = 0;

    while i < left.len() && j < right.len() {
        if left[i] <= right[j] {
            result.push(left[i].clone());
            i += 1;
        } else {
            result.push(right[j].clone());
            j += 1;
        }
    }

    result.extend_from_slice(&left[i..]);
    result.extend_from_slice(&right[j..]);
    result
}
```

#### 2.2.3. 复杂度分析

**时间复杂度**：

- **所有情况**：$T(n) = O(n \log n)$
  - 递归深度：$\log n$
  - 每层合并：$O(n)$

**空间复杂度**：

- $S(n) = O(n)$（需要临时数组）

**稳定性**：稳定排序算法

### 2.3. 堆排序（Heap Sort）

**堆排序**利用堆数据结构进行排序，是一种原地排序算法。

#### 2.3.1. 算法原理

**基本思想**：

1. 构建最大堆（或最小堆）
2. 将堆顶元素与最后一个元素交换
3. 减小堆大小，重新堆化
4. 重复步骤2-3直到堆为空

**形式化定义**：

$$\text{HeapSort}(A) = \text{ExtractMax}(\text{BuildHeap}(A))$$

#### 2.3.2. 算法实现

**Python实现**：

```python
def heap_sort(arr):
    """
    堆排序算法

    时间复杂度：
    - 所有情况：O(n log n)

    空间复杂度：O(1)（原地排序）
    """
    n = len(arr)

    # 构建最大堆
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)

    # 逐个提取堆顶元素
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]  # 交换
        heapify(arr, i, 0)  # 重新堆化


def heapify(arr, n, i):
    """堆化函数，维护堆性质"""
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2

    # 找到最大值
    if left < n and arr[left] > arr[largest]:
        largest = left

    if right < n and arr[right] > arr[largest]:
        largest = right

    # 如果需要交换，递归堆化
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)
```

**Rust实现**：

```rust
/// 堆排序算法（Rust实现）
pub fn heap_sort<T: Ord>(arr: &mut [T]) {
    let n = arr.len();

    // 构建最大堆
    for i in (0..n / 2).rev() {
        heapify(arr, n, i);
    }

    // 逐个提取堆顶元素
    for i in (1..n).rev() {
        arr.swap(0, i);
        heapify(arr, i, 0);
    }
}

fn heapify<T: Ord>(arr: &mut [T], n: usize, i: usize) {
    let mut largest = i;
    let left = 2 * i + 1;
    let right = 2 * i + 2;

    if left < n && arr[left] > arr[largest] {
        largest = left;
    }

    if right < n && arr[right] > arr[largest] {
        largest = right;
    }

    if largest != i {
        arr.swap(i, largest);
        heapify(arr, n, largest);
    }
}
```

#### 2.3.3. 复杂度分析

**时间复杂度**：

- **所有情况**：$T(n) = O(n \log n)$
  - 构建堆：$O(n)$
  - 提取元素：$O(n \log n)$

**空间复杂度**：

- $S(n) = O(1)$（原地排序）

## 3. 查找算法

### 3.1. 二分查找（Binary Search）

**二分查找**是一种在有序数组中查找元素的算法。

#### 3.1.1. 算法原理

**基本思想**：

1. 比较目标值与数组中间元素
2. 如果相等，返回索引
3. 如果目标值小于中间元素，在左半部分查找
4. 如果目标值大于中间元素，在右半部分查找

**形式化定义**：

$$
\text{BinarySearch}(A, x, l, r) = \begin{cases}
-1 & \text{if } l > r \\
m & \text{if } A[m] = x \\
\text{BinarySearch}(A, x, l, m-1) & \text{if } A[m] > x \\
\text{BinarySearch}(A, x, m+1, r) & \text{if } A[m] < x
\end{cases}
$$

其中 $m = \lfloor (l + r) / 2 \rfloor$。

#### 3.1.2. 算法实现

**Python实现**：

```python
def binary_search(arr, target):
    """
    二分查找算法

    时间复杂度：O(log n)
    空间复杂度：O(1)（迭代版本）或 O(log n)（递归版本）

    前提条件：数组必须是有序的
    """
    left, right = 0, len(arr) - 1

    while left <= right:
        mid = (left + right) // 2

        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1  # 未找到


# 递归版本
def binary_search_recursive(arr, target, left=0, right=None):
    """递归版本的二分查找"""
    if right is None:
        right = len(arr) - 1

    if left > right:
        return -1

    mid = (left + right) // 2

    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, right)
    else:
        return binary_search_recursive(arr, target, left, mid - 1)
```

**Rust实现**：

```rust
/// 二分查找算法（Rust实现）
pub fn binary_search<T: Ord>(arr: &[T], target: &T) -> Option<usize> {
    let mut left = 0;
    let mut right = arr.len();

    while left < right {
        let mid = left + (right - left) / 2;

        match arr[mid].cmp(target) {
            std::cmp::Ordering::Equal => return Some(mid),
            std::cmp::Ordering::Less => left = mid + 1,
            std::cmp::Ordering::Greater => right = mid,
        }
    }

    None
}
```

**Go实现**：

```go
// BinarySearch 二分查找算法（Go实现）
func BinarySearch(arr []int, target int) int {
    left, right := 0, len(arr)-1

    for left <= right {
        mid := left + (right-left)/2

        if arr[mid] == target {
            return mid
        } else if arr[mid] < target {
            left = mid + 1
        } else {
            right = mid - 1
        }
    }

    return -1
}
```

#### 3.1.3. 复杂度分析

**时间复杂度**：

- $T(n) = O(\log n)$
  - 每次比较将搜索空间减半
  - 最多需要 $\log_2 n$ 次比较

**空间复杂度**：

- 迭代版本：$O(1)$
- 递归版本：$O(\log n)$（递归栈）

### 3.2. 哈希查找（Hash Search）

**哈希查找**利用哈希表实现快速查找。

#### 3.2.1. 算法原理

**基本思想**：

1. 使用哈希函数将键映射到数组索引
2. 处理哈希冲突（链地址法或开放地址法）
3. 在哈希表中查找元素

**形式化定义**：

$$\text{HashSearch}(H, k) = H[h(k)]$$

其中 $h$ 是哈希函数，$H$ 是哈希表。

#### 3.2.2. 算法实现

**Python实现**：

```python
class HashTable:
    """哈希表实现（使用链地址法处理冲突）"""

    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]

    def _hash(self, key):
        """哈希函数"""
        return hash(key) % self.size

    def insert(self, key, value):
        """插入键值对"""
        index = self._hash(key)
        bucket = self.table[index]

        # 检查键是否已存在
        for i, (k, v) in enumerate(bucket):
            if k == key:
                bucket[i] = (key, value)
                return

        # 添加新键值对
        bucket.append((key, value))

    def search(self, key):
        """查找键对应的值"""
        index = self._hash(key)
        bucket = self.table[index]

        for k, v in bucket:
            if k == key:
                return v

        return None  # 未找到

    def delete(self, key):
        """删除键值对"""
        index = self._hash(key)
        bucket = self.table[index]

        for i, (k, v) in enumerate(bucket):
            if k == key:
                del bucket[i]
                return True

        return False  # 未找到
```

**Rust实现**：

```rust
use std::collections::HashMap;

/// 哈希查找（使用标准库）
pub fn hash_search(map: &HashMap<i32, String>, key: &i32) -> Option<&String> {
    map.get(key)
}

/// 自定义哈希表实现
pub struct HashTable<K, V> {
    buckets: Vec<Vec<(K, V)>>,
    size: usize,
}

impl<K: std::hash::Hash + Eq, V> HashTable<K, V> {
    pub fn new(size: usize) -> Self {
        HashTable {
            buckets: vec![Vec::new(); size],
            size,
        }
    }

    fn hash(&self, key: &K) -> usize {
        use std::hash::{Hash, Hasher};
        let mut hasher = std::collections::hash_map::DefaultHasher::new();
        key.hash(&mut hasher);
        (hasher.finish() as usize) % self.size
    }

    pub fn insert(&mut self, key: K, value: V) {
        let index = self.hash(&key);
        let bucket = &mut self.buckets[index];

        for (k, v) in bucket.iter_mut() {
            if k == &key {
                *v = value;
                return;
            }
        }

        bucket.push((key, value));
    }

    pub fn search(&self, key: &K) -> Option<&V> {
        let index = self.hash(key);
        let bucket = &self.buckets[index];

        for (k, v) in bucket {
            if k == key {
                return Some(v);
            }
        }

        None
    }
}
```

#### 3.2.3. 复杂度分析

**时间复杂度**：

- **平均情况**：$O(1)$
- **最坏情况**：$O(n)$（所有元素哈希到同一位置）

**空间复杂度**：

- $O(n)$（存储所有元素）

## 4. 聚合算法

### 4.1. 基本聚合函数

**聚合函数**对一组值进行计算，返回单个值。

#### 4.1.1. SUM（求和）

**定义**：

$$\text{SUM}(A) = \sum_{i=1}^{n} a_i$$

**实现**：

```python
def sum_aggregate(values):
    """求和聚合函数"""
    return sum(values)


# 流式处理版本（适用于大数据）
def sum_stream(iterator):
    """流式求和，适用于大数据集"""
    total = 0
    for value in iterator:
        total += value
    return total
```

**SQL实现**：

```sql
SELECT SUM(amount) FROM orders;
```

#### 4.1.2. AVG（平均值）

**定义**：

$$\text{AVG}(A) = \frac{1}{n} \sum_{i=1}^{n} a_i = \frac{\text{SUM}(A)}{n}$$

**实现**：

```python
def avg_aggregate(values):
    """平均值聚合函数"""
    if not values:
        return None
    return sum(values) / len(values)


# 流式处理版本（避免存储所有值）
def avg_stream(iterator):
    """流式计算平均值"""
    total = 0
    count = 0
    for value in iterator:
        total += value
        count += 1
    return total / count if count > 0 else None
```

**SQL实现**：

```sql
SELECT AVG(amount) FROM orders;
```

#### 4.1.3. COUNT（计数）

**定义**：

$$\text{COUNT}(A) = |A| = n$$

**实现**：

```python
def count_aggregate(values):
    """计数聚合函数"""
    return len(values)


# 流式处理版本
def count_stream(iterator):
    """流式计数"""
    count = 0
    for _ in iterator:
        count += 1
    return count
```

**SQL实现**：

```sql
SELECT COUNT(*) FROM orders;
SELECT COUNT(DISTINCT user_id) FROM orders;
```

#### 4.1.4. MAX/MIN（最大值/最小值）

**定义**：

$$\text{MAX}(A) = \max_{i=1}^{n} a_i$$

$$\text{MIN}(A) = \min_{i=1}^{n} a_i$$

**实现**：

```python
def max_aggregate(values):
    """最大值聚合函数"""
    if not values:
        return None
    return max(values)


def min_aggregate(values):
    """最小值聚合函数"""
    if not values:
        return None
    return min(values)


# 流式处理版本
def max_stream(iterator):
    """流式计算最大值"""
    max_val = None
    for value in iterator:
        if max_val is None or value > max_val:
            max_val = value
    return max_val
```

**SQL实现**：

```sql
SELECT MAX(amount) FROM orders;
SELECT MIN(amount) FROM orders;
```

### 4.2. 分组聚合

**分组聚合**先按某个键分组，然后对每组进行聚合。

#### 4.2.1. 哈希分组聚合

**算法流程**：

1. 使用哈希表按分组键分组
2. 对每组应用聚合函数
3. 返回结果

**实现**：

```python
def group_by_aggregate(data, group_key, agg_func):
    """
    分组聚合函数

    参数：
    - data: 数据列表，每个元素是字典
    - group_key: 分组键（函数或字符串）
    - agg_func: 聚合函数

    返回：分组聚合结果
    """
    groups = {}

    # 分组
    for item in data:
        key = group_key(item) if callable(group_key) else item[group_key]
        if key not in groups:
            groups[key] = []
        groups[key].append(item)

    # 聚合
    result = {}
    for key, group in groups.items():
        result[key] = agg_func(group)

    return result


# 使用示例
data = [
    {'user_id': 1, 'amount': 100},
    {'user_id': 1, 'amount': 200},
    {'user_id': 2, 'amount': 150},
]

# 按user_id分组，计算总金额
result = group_by_aggregate(
    data,
    group_key='user_id',
    agg_func=lambda group: sum(item['amount'] for item in group)
)
# 结果: {1: 300, 2: 150}
```

**SQL实现**：

```sql
SELECT user_id, SUM(amount)
FROM orders
GROUP BY user_id;
```

#### 4.2.2. 排序分组聚合

**算法流程**：

1. 按分组键排序
2. 遍历排序后的数据，识别分组边界
3. 对每组应用聚合函数

**实现**：

```python
def group_by_sort_aggregate(data, group_key, agg_func):
    """使用排序的分组聚合（适用于需要有序结果的场景）"""
    # 排序
    sorted_data = sorted(data, key=lambda x: group_key(x) if callable(group_key) else x[group_key])

    result = []
    current_key = None
    current_group = []

    for item in sorted_data:
        key = group_key(item) if callable(group_key) else item[group_key]

        if key != current_key:
            # 处理前一组
            if current_group:
                result.append({
                    'key': current_key,
                    'value': agg_func(current_group)
                })
            # 开始新组
            current_key = key
            current_group = [item]
        else:
            current_group.append(item)

    # 处理最后一组
    if current_group:
        result.append({
            'key': current_key,
            'value': agg_func(current_group)
        })

    return result
```

### 4.3. 窗口函数

**窗口函数**对一组相关的行进行计算，而不将结果合并为单行。

#### 4.3.1. 窗口函数类型

1. **聚合窗口函数**：SUM、AVG、COUNT等
2. **排名窗口函数**：RANK、DENSE_RANK、ROW_NUMBER
3. **值窗口函数**：LAG、LEAD、FIRST_VALUE、LAST_VALUE

**SQL示例**：

```sql

```

## 5. 分组算法

### 5.1. 哈希分组

**哈希分组**使用哈希表快速分组。

**算法复杂度**：

- 时间复杂度：$O(n)$
- 空间复杂度：$O(n)$

**实现**：

```python
def hash_group(data, key_func):
    """哈希分组"""
    groups = {}
    for item in data:
        key = key_func(item)
        if key not in groups:
            groups[key] = []
        groups[key].append(item)
    return groups
```

### 5.2. 排序分组

**排序分组**先排序后分组。

**算法复杂度**：

- 时间复杂度：$O(n \log n)$
- 空间复杂度：$O(n)$

**实现**：

```python
def sort_group(data, key_func):
    """排序分组"""
    sorted_data = sorted(data, key=key_func)
    groups = []
    current_key = None
    current_group = []

    for item in sorted_data:
        key = key_func(item)
        if key != current_key:
            if current_group:
                groups.append((current_key, current_group))
            current_key = key
            current_group = [item]
        else:
            current_group.append(item)

    if current_group:
        groups.append((current_key, current_group))

    return groups
```

### 5.3. 混合分组

**混合分组**结合哈希和排序的优势。

**策略**：

- 小数据集：使用哈希分组
- 大数据集：使用排序分组（更好的缓存局部性）

## 6. 并行与分布式处理

### 6.1. MapReduce模型

**MapReduce**是一种编程模型，用于处理和生成大数据集。

#### 6.1.1. MapReduce流程

1. **Map阶段**：将输入数据映射为键值对
2. **Shuffle阶段**：按键分组
3. **Reduce阶段**：对每组进行归约

**形式化定义**：

$$\text{MapReduce}(D) = \text{Reduce}(\text{Shuffle}(\text{Map}(D)))$$

#### 6.1.2. 实现示例

**Python实现（简化版）**：

```python
def map_reduce(data, map_func, reduce_func):
    """
    MapReduce实现

    参数：
    - data: 输入数据
    - map_func: Map函数，输入一个元素，输出键值对列表
    - reduce_func: Reduce函数，输入键和值列表，输出结果
    """
    # Map阶段
    mapped = []
    for item in data:
        mapped.extend(map_func(item))

    # Shuffle阶段（分组）
    groups = {}
    for key, value in mapped:
        if key not in groups:
            groups[key] = []
        groups[key].append(value)

    # Reduce阶段
    result = []
    for key, values in groups.items():
        result.append((key, reduce_func(key, values)))

    return result


# 使用示例：词频统计
def word_count_map(doc):
    """Map函数：将文档分割为单词"""
    words = doc.split()
    return [(word, 1) for word in words]


def word_count_reduce(key, values):
    """Reduce函数：统计单词出现次数"""
    return sum(values)


# 使用
documents = ["hello world", "hello python", "world python"]
result = map_reduce(documents, word_count_map, word_count_reduce)
# 结果: [('hello', 2), ('world', 2), ('python', 2)]
```

### 6.2. 并行归约

**并行归约**将归约操作并行化。

**实现**：

```python
from multiprocessing import Pool

def parallel_reduce(data, reduce_func, num_workers=4):
    """并行归约"""
    # 分割数据
    chunk_size = len(data) // num_workers
    chunks = [data[i:i+chunk_size] for i in range(0, len(data), chunk_size)]

    # 并行处理
    with Pool(num_workers) as pool:
        results = pool.map(reduce_func, chunks)

    # 合并结果
    return reduce_func(results)
```

### 6.3. 分治算法

**分治算法**将问题分解为子问题，递归求解后合并。

**通用模板**：

```python
def divide_and_conquer(problem):
    """分治算法模板"""
    # 基本情况
    if is_base_case(problem):
        return solve_base_case(problem)

    # 分解
    subproblems = divide(problem)

    # 递归求解
    subresults = [divide_and_conquer(sub) for sub in subproblems]

    # 合并
    return combine(subresults)
```

class StreamingAggregator:

        self.sum = 0

        self.max = None

## 8. 形式化定义与证明

### 8.1. 排序算法的正确性

**定理**：快速排序算法正确地将数组排序。

**证明**：

1. **基本情况**：当数组长度 $\leq 1$ 时，数组已排序。
2. **归纳假设**：假设对于长度 $< n$ 的数组，快速排序正确。
3. **归纳步骤**：
   - 选择基准 $p$
   - 分割数组为 $L$（小于 $p$）和 $R$（大于 $p$）
   - 递归排序 $L$ 和 $R$
   - 合并：$L \cup \{p\} \cup R$ 已排序

因此，快速排序正确。□

### 8.2. 二分查找的正确性

**定理**：二分查找在有序数组中找到目标元素（如果存在）。

**证明**：

使用循环不变量：如果目标元素在数组中，它一定在 $[left, right]$ 范围内。

1. **初始化**：$left = 0, right = n-1$，不变量成立。
2. **保持**：每次迭代缩小搜索范围，不变量保持。
3. **终止**：当 $left > right$ 时，搜索范围为空，元素不存在。

因此，二分查找正确。□
