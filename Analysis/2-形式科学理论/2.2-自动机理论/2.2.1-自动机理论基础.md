## 1. 摘要

自动机理论是计算理论的核心分支，研究抽象计算模型的形式化定义、性质和计算能力。本文档系统梳理自动机理论基础，涵盖有限自动机、下推自动机、图灵机等基本概念，以及计算复杂性、可计算性理论等核心内容，为计算机科学和软件工程提供重要的理论基础。

## 2. 自动机理论概述

### 2.1. 自动机理论的定义

**自动机理论（Automata Theory）**是研究抽象计算模型和形式语言的数学理论，它提供了计算的形式化基础。

**自动机的核心概念**：

1. **状态（State）**：系统在某个时刻的配置
2. **转移（Transition）**：从一个状态到另一个状态的变化
3. **输入（Input）**：系统接收的符号序列
4. **接受（Acceptance）**：系统对输入的判定结果

**自动机理论的研究内容**：

- **自动机模型**：DFA、NFA、PDA、TM等
- **语言识别**：自动机接受的语言类
- **计算能力**：不同自动机的计算能力
- **复杂性分析**：时间和空间复杂性

### 2.2. 自动机理论的发展历程

**自动机理论发展时间线**：

1. **1936年**：图灵提出图灵机模型（Turing, 1936）
2. **1943年**：McCulloch和Pitts提出神经网络模型
3. **1951年**：Kleene提出正则表达式
4. **1956年**：Chomsky提出形式语言层次
5. **1959年**：Rabin和Scott证明DFA与NFA等价
6. **1960s**：下推自动机理论发展
7. **1970s**：计算复杂性理论建立

### 2.3. 自动机的分类

**按计算能力分类**：

1. **有限自动机（FA）**：识别正则语言
2. **下推自动机（PDA）**：识别上下文无关语言
3. **线性有界自动机（LBA）**：识别上下文相关语言
4. **图灵机（TM）**：识别递归可枚举语言

**按确定性分类**：

1. **确定性自动机**：每个状态和输入符号有唯一转移
2. **非确定性自动机**：每个状态和输入符号可能有多个转移

## 3. 概述

自动机理论是计算理论的核心分支，研究抽象计算模型的形式化定义、性质和计算能力。本模块介绍有限自动机、下推自动机、图灵机等基本概念。

## 有限自动机 (FA)

### 3.1. 确定性有限自动机 (DFA)

#### 3.1.1. DFA形式化定义

**定义 3.1.1（确定性有限自动机）**:

确定性有限自动机是一个五元组 $M = (Q, \Sigma, \delta, q_0, F)$，其中：

- $Q$：有限状态集合
- $\Sigma$：有限输入字母表
- $\delta: Q \times \Sigma \to Q$：转移函数
- $q_0 \in Q$：初始状态
- $F \subseteq Q$：接受状态集合

**扩展转移函数**：

$$\delta^*(q, \varepsilon) = q$$

$$\delta^*(q, wa) = \delta(\delta^*(q, w), a)$$

其中 $w \in \Sigma^*$，$a \in \Sigma$。

**语言接受**：

$$L(M) = \{w \in \Sigma^* \mid \delta^*(q_0, w) \in F\}$$

#### 3.1.2. DFA实现示例

```python
class DFA:
    def __init__(self, states, alphabet, transitions, start_state, accept_states):
        self.states = states
        self.alphabet = alphabet
        self.transitions = transitions
        self.start_state = start_state
        self.accept_states = accept_states

    def process(self, input_string):
        """处理输入字符串"""
        current_state = self.start_state
        for symbol in input_string:
            if symbol not in self.alphabet:
                return False
            if (current_state, symbol) not in self.transitions:
                return False
            current_state = self.transitions[(current_state, symbol)]
        return current_state in self.accept_states

# 示例：识别以"ab"结尾的字符串
dfa = DFA(
    states={'q0', 'q1', 'q2'},
    alphabet={'a', 'b'},
    transitions={
        ('q0', 'a'): 'q1', ('q0', 'b'): 'q0',
        ('q1', 'a'): 'q1', ('q1', 'b'): 'q2',
        ('q2', 'a'): 'q1', ('q2', 'b'): 'q0',
    },
    start_state='q0',
    accept_states={'q2'}
)
```

### 3.2. 非确定性有限自动机 (NFA)

#### 3.2.1. NFA形式化定义

**定义 3.2.1（非确定性有限自动机）**:

非确定性有限自动机是一个五元组 $M = (Q, \Sigma, \delta, q_0, F)$，其中：

- $Q$：有限状态集合
- $\Sigma$：有限输入字母表
- $\delta: Q \times \Sigma \to 2^Q$：转移函数（返回状态集合）
- $q_0 \in Q$：初始状态
- $F \subseteq Q$：接受状态集合

**扩展转移函数**：

$$\delta^*(q, \varepsilon) = \{q\}$$

$$\delta^*(q, wa) = \bigcup_{p \in \delta^*(q, w)} \delta(p, a)$$

**语言接受**：

$$L(M) = \{w \in \Sigma^* \mid \delta^*(q_0, w) \cap F \neq \emptyset\}$$

#### 3.2.2. NFA实现示例

```python
class NFA:
    def __init__(self, states, alphabet, transitions, start_state, accept_states):
        self.states = states
        self.alphabet = alphabet
        self.transitions = transitions  # (state, symbol) -> set of states
        self.start_state = start_state
        self.accept_states = accept_states

    def epsilon_closure(self, states):
        """计算ε闭包"""
        closure = set(states)
        stack = list(states)
        while stack:
            state = stack.pop()
            if (state, 'ε') in self.transitions:
                for next_state in self.transitions[(state, 'ε')]:
                    if next_state not in closure:
                        closure.add(next_state)
                        stack.append(next_state)
        return closure

    def process(self, input_string):
        """处理输入字符串"""
        current_states = self.epsilon_closure({self.start_state})
        for symbol in input_string:
            next_states = set()
            for state in current_states:
                if (state, symbol) in self.transitions:
                    next_states.update(self.transitions[(state, symbol)])
            current_states = self.epsilon_closure(next_states)
        return bool(current_states & self.accept_states)
```

### 3.3. DFA与NFA等价性

#### 3.3.1. 子集构造法

**定理 3.3.1（NFA与DFA等价）**:

对于每个NFA $M$，存在等价的DFA $M'$ 使得 $L(M) = L(M')$。

**子集构造法**：

给定NFA $M = (Q, \Sigma, \delta, q_0, F)$，构造DFA $M' = (Q', \Sigma, \delta', q_0', F')$：

1. **状态集合**：$Q' = 2^Q$（NFA状态集合的幂集）
2. **初始状态**：$q_0' = \text{ECLOSE}(q_0)$
3. **转移函数**：$\delta'(S, a) = \bigcup_{q \in S} \text{ECLOSE}(\delta(q, a))$
4. **接受状态**：$F' = \{S \subseteq Q \mid S \cap F \neq \emptyset\}$

#### 3.3.2. 等价性证明

**证明思路**：

1. **语言包含**：$L(M) \subseteq L(M')$
   - 对于 $w \in L(M)$，存在接受路径
   - DFA $M'$ 模拟NFA $M$ 的所有可能路径
   - 因此 $w \in L(M')$

2. **语言包含**：$L(M') \subseteq L(M)$
   - 对于 $w \in L(M')$，DFA $M'$ 到达接受状态
   - 该接受状态对应NFA $M$ 的接受状态集合
   - 因此 $w \in L(M)$

## 4. 下推自动机 (PDA)

### 4.1. PDA形式化定义

#### 4.1.1. PDA基本结构

**定义 4.1.1（下推自动机）**:

下推自动机是一个七元组 $M = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)$，其中：

- $Q$：有限状态集合
- $\Sigma$：有限输入字母表
- $\Gamma$：有限栈字母表
- $\delta: Q \times (\Sigma \cup \{\varepsilon\}) \times \Gamma \to 2^{Q \times \Gamma^*}$：转移函数
- $q_0 \in Q$：初始状态
- $Z_0 \in \Gamma$：初始栈符号
- $F \subseteq Q$：接受状态集合

**PDA配置**：

配置是一个三元组 $(q, w, \gamma)$，其中：

- $q \in Q$：当前状态
- $w \in \Sigma^*$：剩余输入
- $\gamma \in \Gamma^*$：栈内容

**转移关系**：

$$(q, aw, Z\gamma) \vdash (p, w, \alpha\gamma)$$

当且仅当 $(p, \alpha) \in \delta(q, a, Z)$。

**语言接受**：

$$L(M) = \{w \in \Sigma^* \mid (q_0, w, Z_0) \vdash^* (q, \varepsilon, \gamma), q \in F\}$$

#### 4.1.2. PDA实现示例

```python
class PDA:
    def __init__(self, states, alphabet, stack_alphabet, transitions,
                 start_state, start_stack_symbol, accept_states):
        self.states = states
        self.alphabet = alphabet
        self.stack_alphabet = stack_alphabet
        self.transitions = transitions
        self.start_state = start_state
        self.start_stack_symbol = start_stack_symbol
        self.accept_states = accept_states

    def process(self, input_string):
        """处理输入字符串（按最终状态接受）"""
        configs = [(self.start_state, input_string, [self.start_stack_symbol])]
        while configs:
            state, remaining, stack = configs.pop()
            if not remaining and state in self.accept_states:
                return True
            current_input = remaining[0] if remaining else 'ε'
            stack_top = stack[-1] if stack else None
            for input_symbol in [current_input, 'ε']:
                if (state, input_symbol, stack_top) in self.transitions:
                    for next_state, stack_push in self.transitions[(state, input_symbol, stack_top)]:
                        new_remaining = remaining[1:] if input_symbol == current_input and remaining else remaining
                        new_stack = stack[:-1] + list(reversed(stack_push))
                        configs.append((next_state, new_remaining, new_stack))
        return False
```

### 4.2. 上下文无关文法与PDA

#### 4.2.1. 上下文无关文法

**定义 4.2.1（上下文无关文法）**:

上下文无关文法是一个四元组 $G = (V, T, P, S)$，其中：

- $V$：非终结符集合
- $T$：终结符集合
- $P$：产生式集合，形式为 $A \to \alpha$，其中 $A \in V$，$\alpha \in (V \cup T)^*$
- $S \in V$：开始符号

#### 4.2.2. PDA与CFG等价性

**定理 4.2.1（PDA与CFG等价）**:

语言 $L$ 是上下文无关的当且仅当存在PDA $M$ 使得 $L(M) = L$。

**证明思路**：

1. **CFG到PDA**：构造PDA模拟CFG的推导
2. **PDA到CFG**：从PDA构造等价的CFG

## 5. 图灵机 (TM)

### 5.1. 基本图灵机

#### 5.1.1. 图灵机形式化定义

**定义 5.1.1（图灵机）**:

图灵机是一个七元组 $M = (Q, \Sigma, \Gamma, \delta, q_0, B, F)$，其中：

- $Q$：有限状态集合
- $\Sigma$：有限输入字母表
- $\Gamma$：有限带字母表，$\Sigma \subseteq \Gamma$
- $\delta: Q \times \Gamma \to Q \times \Gamma \times \{L, R\}$：转移函数
- $q_0 \in Q$：初始状态
- $B \in \Gamma \setminus \Sigma$：空白符号
- $F \subseteq Q$：接受状态集合

**图灵机配置**：

配置是一个三元组 $(q, \alpha, \beta)$，其中：

- $q \in Q$：当前状态
- $\alpha \in \Gamma^*$：带头左侧的带内容
- $\beta \in \Gamma^*$：带头位置及其右侧的带内容

**转移关系**：

$$(q, X\alpha, Y\beta) \vdash (p, X\alpha, Z\beta)$$

如果 $\delta(q, Y) = (p, Z, R)$。

**语言接受**：

$$L(M) = \{w \in \Sigma^* \mid (q_0, \varepsilon, w) \vdash^* (q, \alpha, \beta), q \in F\}$$

#### 5.1.2. 图灵机实现示例

```python
class TuringMachine:
    def __init__(self, states, alphabet, tape_alphabet, transitions,
                 start_state, blank_symbol, accept_states):
        self.states = states
        self.alphabet = alphabet
        self.tape_alphabet = tape_alphabet
        self.transitions = transitions
        self.start_state = start_state
        self.blank_symbol = blank_symbol
        self.accept_states = accept_states

    def run(self, input_string, max_steps=10000):
        """运行图灵机"""
        tape_left = []
        tape_right = list(input_string)
        current_state = self.start_state
        head_pos = 0
        steps = 0
        while current_state not in self.accept_states and steps < max_steps:
            steps += 1
            current_symbol = tape_right[head_pos] if head_pos < len(tape_right) else self.blank_symbol
            if (current_state, current_symbol) not in self.transitions:
                return False, steps
            next_state, write_symbol, direction = self.transitions[(current_state, current_symbol)]
            if head_pos < len(tape_right):
                tape_right[head_pos] = write_symbol
            else:
                tape_right.append(write_symbol)
            if direction == 'R':
                head_pos += 1
            elif direction == 'L' and head_pos > 0:
                head_pos -= 1
            current_state = next_state
        return current_state in self.accept_states, steps
```

### 5.2. 图灵机变体

#### 5.2.1. 多带图灵机

**定义 5.2.1（k带图灵机）**:

k带图灵机有k条带，每条带都有自己的带头。

**定理 5.2.1（多带图灵机等价性）**:

k带图灵机与单带图灵机等价。

#### 5.2.2. 非确定性图灵机

**定义 5.2.2（非确定性图灵机）**:

非确定性图灵机的转移函数为：

$$\delta: Q \times \Gamma \to 2^{Q \times \Gamma \times \{L, R\}}$$

**定理 5.2.2（非确定性图灵机等价性）**:

非确定性图灵机与确定性图灵机等价（在计算能力上）。

#### 5.2.3. 通用图灵机

**定义 5.2.3（通用图灵机）**:

通用图灵机可以模拟任意图灵机的计算。

**定理 5.2.3（通用图灵机存在性）**:

存在通用图灵机 $U$，对于任意图灵机 $M$ 和输入 $w$：

$$U(\langle M, w \rangle) = M(w)$$

## 6. 计算复杂性

### 6.1. 时间复杂性

#### 6.1.1. 时间复杂性定义

**定义 6.1.1（时间复杂性）**:

对于图灵机 $M$，时间复杂性函数 $T_M: \mathbb{N} \to \mathbb{N}$ 定义为：

$$T_M(n) = \max\{t \mid \text{存在长度为}n\text{的输入}w\text{，}M\text{在}w\text{上运行}t\text{步}\}$$

#### 6.1.2. 大O记号

**定义 6.1.2（大O记号）**:

$$f(n) = O(g(n)) \Leftrightarrow \exists c > 0, n_0 > 0: \forall n \geq n_0, f(n) \leq c \cdot g(n)$$

**常见时间复杂性类**：

- $O(1)$：常数时间
- $O(\log n)$：对数时间
- $O(n)$：线性时间
- $O(n \log n)$：线性对数时间
- $O(n^2)$：平方时间
- $O(2^n)$：指数时间

### 6.2. 空间复杂性

#### 6.2.1. 空间复杂性定义

**定义 6.2.1（空间复杂性）**:

对于图灵机 $M$，空间复杂性函数 $S_M: \mathbb{N} \to \mathbb{N}$ 定义为：

$$S_M(n) = \max\{s \mid \text{存在长度为}n\text{的输入}w\text{，}M\text{在}w\text{上使用}s\text{个带格子}\}$$

### 6.3. 复杂性类

#### 6.3.1. P类

**定义 6.3.1（P类）**:

$$P = \bigcup_{k \geq 0} \text{TIME}(n^k)$$

P类包含所有在多项式时间内可判定的语言。

#### 6.3.2. NP类

**定义 6.3.2（NP类）**:

$$NP = \bigcup_{k \geq 0} \text{NTIME}(n^k)$$

NP类包含所有在非确定性多项式时间内可判定的语言。

**NP完全问题**：

- 布尔可满足性问题（SAT）
- 旅行商问题（TSP）
- 图着色问题

#### 6.3.3. PSPACE类

**定义 6.3.3（PSPACE类）**:

$$PSPACE = \bigcup_{k \geq 0} \text{SPACE}(n^k)$$

PSPACE类包含所有在多项式空间内可判定的语言。

**复杂性类包含关系**：

$$P \subseteq NP \subseteq PSPACE \subseteq EXPTIME$$

## 7. 可计算性理论

### 7.1. 可判定性

#### 7.1.1. 可判定问题

**定义 7.1.1（可判定问题）**:

问题 $P$ 是可判定的，如果存在图灵机 $M$，对于所有输入：

- 如果输入 $\in P$，$M$ 接受
- 如果输入 $\notin P$，$M$ 拒绝

**可判定问题示例**：

- 正则语言成员问题
- 上下文无关语言成员问题
- 有限自动机等价问题

#### 7.1.2. 不可判定问题

**不可判定问题示例**：

- 停机问题
- Post对应问题
- 图灵机等价问题

### 7.2. 停机问题

#### 7.2.1. 停机问题定义

**定义 7.2.1（停机问题）**:

停机问题是：给定图灵机 $M$ 和输入 $w$，判断 $M$ 在 $w$ 上是否停机。

#### 7.2.2. 不可判定性证明

**定理 7.2.1（停机问题不可判定）**:

停机问题是不可判定的。

**证明**（反证法）：

假设存在图灵机 $H$ 判定停机问题。构造图灵机 $D$：

$$
D(\langle M \rangle) = \begin{cases}
\text{接受} & \text{如果}H(\langle M, \langle M \rangle \rangle)\text{拒绝} \\
\text{循环} & \text{如果}H(\langle M, \langle M \rangle \rangle)\text{接受}
\end{cases}
$$

考虑 $D(\langle D \rangle)$ 会导致矛盾，因此停机问题是不可判定的。

### 7.3. 递归可枚举性

#### 7.3.1. 递归语言

**定义 7.3.1（递归语言）**:

语言 $L$ 是递归的，如果存在图灵机 $M$：

- 如果 $w \in L$，$M$ 接受 $w$
- 如果 $w \notin L$，$M$ 拒绝 $w$

#### 7.3.2. 递归可枚举语言

**定义 7.3.2（递归可枚举语言）**:

语言 $L$ 是递归可枚举的，如果存在图灵机 $M$：

- 如果 $w \in L$，$M$ 接受 $w$
- 如果 $w \notin L$，$M$ 可能拒绝或永不停机

**关系**：

$$\text{递归语言} \subset \text{递归可枚举语言}$$

### 8.2. 正则表达式

#### 8.2.1. 正则表达式定义

**定义 8.2.1（正则表达式）**:

正则表达式的语法：

$$E ::= \emptyset \mid \varepsilon \mid a \mid E + E \mid E \cdot E \mid E^*$$

其中 $a \in \Sigma$。

#### 8.2.2. 正则表达式与DFA等价性

**定理 8.2.1（正则表达式与DFA等价）**:

语言 $L$ 是正则的当且仅当存在正则表达式 $E$ 使得 $L(E) = L$。

**证明思路**：

1. **正则表达式到DFA**：通过Thompson构造法
2. **DFA到正则表达式**：通过状态消除法

#### 8.3.1. Chomsky层次

**Chomsky层次**：

1. **类型0（递归可枚举语言）**：图灵机
2. **类型1（上下文相关语言）**：线性有界自动机
3. **类型2（上下文无关语言）**：下推自动机

$$\text{正则语言} \subset \text{上下文无关语言} \subset \text{上下文相关语言} \subset \text{递归可枚举语言}$$

## 自动机实现

### DFA实现

```python
class DFA:
    def __init__(self, states, alphabet, transitions, start_state, accept_states):
        self.states = states
        self.alphabet = alphabet
        self.transitions = transitions
        self.current_state = start_state
        self.accept_states = accept_states

    def process(self, input_string):
        for symbol in input_string:
            if symbol not in self.alphabet:
                return False
            self.current_state = self.transitions[self.current_state][symbol]
        return self.current_state in self.accept_states
```

### 图灵机实现

```python
class TuringMachine:
    def __init__(self, states, alphabet, transitions, start_state, accept_states):
        self.states = states
        self.alphabet = alphabet
        self.transitions = transitions
        self.current_state = start_state
        self.accept_states = accept_states
        self.tape = []
        self.head = 0

    def run(self, input_string):
        self.tape = list(input_string)
        self.head = 0

        while self.current_state not in self.accept_states:
            current_symbol = self.tape[self.head] if self.head < len(self.tape) else 'B'
            if (self.current_state, current_symbol) not in self.transitions:
                return False

            new_state, new_symbol, direction = self.transitions[(self.current_state, current_symbol)]
            self.tape[self.head] = new_symbol
            self.current_state = new_state

            if direction == 'R':
                self.head += 1
            elif direction == 'L':
                self.head -= 1

        return True
```
